主流程（灰色实线 = spawn，prompt 自包含） 协商子循环（条件触发，最多 2–3 轮） 产物落盘（指挥与仲裁只信任文件里的数字）

三条出口，一条纪律。「领域外 → 明示拒答」这条分支不能省——垂直 agent 的标志不是它会什么，而是它能不能明确拒绝什么。
快通道跳过指挥与仲裁。问"陆军多少人"不该让三位参谋各发一遍言，这是按需编排，不是固定流水线。
协商是条件触发的增量层。默认走中心化裁决，只有检测到共享资源冲突时，才拉起冲突相关的参谋开 2–3 轮联席会；仍不收敛则由仲裁按优先级强制裁决。
